# Baratie

Projeto que desenvolvi durante meus estudos de Python na Alura.

O **Baratie** é um programa simples de gerenciamento de restaurantes feito em Python e executado pelo terminal. A ideia foi usar o projeto para praticar os conceitos que eu estava aprendendo no curso e entender melhor como organizar um programa em funções.

## Sobre o projeto

O programa funciona diretamente pelo terminal e permite:

- Cadastrar novos restaurantes
- Informar a categoria de cada restaurante
- Listar os restaurantes cadastrados
- Ver se um restaurante está aberto ou fechado
- Alterar o status de um restaurante
- Navegar pelas opções através de um menu


## O que aprendi

Durante o desenvolvimento do projeto, pratiquei vários conceitos básicos de Python.

### Funções

Separei as partes do programa em funções diferentes, como cadastro, listagem, alteração de status e controle do menu.

Isso me ajudou a entender melhor como organizar o código e evitar deixar tudo concentrado em um único lugar.

### Listas e dicionários

Usei uma lista para armazenar os restaurantes e dicionários para guardar as informações de cada um.

Cada restaurante possui:

- Nome
- Categoria
- Status

Com isso, pratiquei como armazenar, acessar e alterar informações dentro dessas estruturas.

### Condicionais

Usei `if`, `elif` e `else` para controlar as opções escolhidas no menu e algumas verificações dentro do programa.

### Laços de repetição

Usei `for` para percorrer a lista de restaurantes e mostrar as informações de cada um.

### Entrada e saída de dados

Também pratiquei o uso de `input()` para receber informações pelo terminal e `print()` para mostrar mensagens e resultados para o usuário.

### Valores booleanos

O status dos restaurantes é armazenado usando `True` e `False`.

Isso me ajudou a entender melhor como valores booleanos podem ser usados para controlar estados dentro de um programa.

### Organização e documentação

Durante o projeto também comecei a usar:

- Comentários
- Docstrings
- Nomes de variáveis mais claros
- Funções separadas por responsabilidade

Essas mudanças ajudaram a deixar o código mais organizado e mais fácil de acompanhar.
